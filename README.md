# moment-draft

旅行や友人とのイベントの写真・短い動画から、残したい瞬間を選び直して一本にするWebサービスの検証です。

現在は素材の読込を確かめる段階です。自動初案、場面カードの編集、書き出しは未実装です。

[合意済みの製品方針と未決定事項](PRODUCT.md)を分けて記録しています。速度・品質・原価の実測値はまだありません。

実素材、個人のファイル名、解析結果、認証情報は公開リポジトリへ追加しません。

## 手元で読込を試す

`prototype/browser-intake` ブランチに、製品構成から分離した[ブラウザ読込実験](experiments/intake.html)があります。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory experiments
```

[読込検証ページ](http://127.0.0.1:4173/intake.html)を開き、写真と動画を選びます。HTMLファイルを直接開いても使えます。

写真の向き・色、動画の再生と音を原本と比較してください。画像抽出ボタンで、写真または動画の現在位置から確認用JPEGを作れます。
検証結果は端末へJSONで保存できます。ファイル名を含むため、公開しないでください。

この実験はブラウザの標準機能だけを使い、通信による素材送信や保管を行いません。7日保存やJevのZDRを実装したものではありません。

実施状況は[検証記録](docs/validation.md)に記載します。
