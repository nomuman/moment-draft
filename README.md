# moment-draft

旅行や友人とのイベントの写真・短い動画から、残したい瞬間を選び直して一本にするWebサービスの検証です。

現在は、写真・動画をブラウザから取り込み、初案の場面を差し替え、前後を調整し、BGMを付けてMP4を保存できる試用版です。作品は同じブラウザで開き直せます。素材と作品はサービス側の保存先に置かれ、外部AIには送信しません。

[合意済みの製品方針と未決定事項](PRODUCT.md)を分けて記録しています。初案生成の速度・選別品質・原価はまだ測っていません。

実素材、個人のファイル名、解析結果、認証情報は公開リポジトリへ追加しません。

## 試用版を起動する

Python 3.11 と FFmpeg を用意し、リポジトリのルートで実行します。

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m moment_draft
```

[編集画面](http://127.0.0.1:8770)を開き、写真と動画を選びます。試用出力は横長16:9の720p・30fpsです。縦素材には余白を付け、元の動画の音を残します。3曲のオリジナルBGMと音なしを選べます。候補は素材の時間帯から作り、会話や表情の内容はまだ判定しません。

既定の保存先は `.local/service-data` です。作成から7日で閲覧を拒否し、起動中の自動保守が期限切れのサービス内コピーを削除します。Cookieを消すと作品へ戻れません。既存の保存先を接続する前に[保持方針と運用手順](docs/operations.md)を確認してください。

Dockerでの起動、公開試用の入場制限、公開前の確認も[運用手順](docs/operations.md)にあります。公開先へのデプロイと本番運用は未実施です。[APIと制限](docs/service-api.md)、[BGMの出典](docs/music.md)、[メモリ検証の範囲](docs/render-memory.md)を別に記録しています。

実ブラウザ・実素材・Linuxコンテナでの確認と、公開前に残る判断は[公開準備の記録](docs/release-readiness.md)にまとめています。

## 初期の読込実験

製品構成から分離した[ブラウザ読込実験](experiments/intake.html)があります。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory experiments
```

[読込検証ページ](http://127.0.0.1:4173/intake.html)を開き、写真と動画を選びます。HTMLファイルを直接開いても使えます。

写真の向き・色、動画の再生と音を原本と比較してください。画像抽出ボタンで、写真または動画の現在位置から確認用JPEGを作れます。
検証結果は端末へJSONで保存できます。ファイル名を含むため、公開しないでください。

この実験はブラウザの標準機能だけを使い、通信による素材送信や保管を行いません。7日保存やJevのZDRを実装したものではありません。

実施状況は[検証記録](docs/validation.md)に記載します。
