# moment-draft

旅行や友人とのイベントで撮った写真・短い動画から、残したい瞬間を選び直して一本にまとめるWebサービスの構想です。この公開リポジトリでは製品方針を管理しています。

## 現在の公開内容

現在含まれるのは、このREADME、[製品方針](PRODUCT.md)、[ライセンス](LICENSE)、Gitの除外設定です。実行用コード、依存関係の定義、起動コマンドは含まれていません。

素材の読み込み、自動初案、場面カードによる編集、動画の書き出しを、このリポジトリから起動して試すことはできません。

## 製品として検討していること

- 写真と短い動画を混ぜて、約60秒の動画の初案を作る
- 初案に含める場面を選び直し、動画の前後を調整する
- 横長16:9を基本に、縦素材は余白を付けて収める
- 元の音と少数のBGMを組み合わせる

これらは合意済みの検証方針で、実装済み機能ではありません。素材100点、初案まで1〜3分、手直し5分以内などの数値も検証の目標であり、実測性能や技術上限ではありません。

## 未決定・未検証

言語、フレームワーク、計算基盤、保管先は未決定です。素材形式の対応、編集品質、処理速度、原価、Jevを使う効果も未検証です。課金と7日間の保存は将来の方針で、決済や削除処理の実装を意味しません。

合意事項、目標、未決定事項は [PRODUCT.md](PRODUCT.md) で分けて記録しています。実素材、個人のファイル名、解析結果、認証情報は公開リポジトリへ追加しません。
