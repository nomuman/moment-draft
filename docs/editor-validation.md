# 編集・書き出しの検証

2026-10-18、ローカル編集実験をPCブラウザから操作した。製品の構成、対応形式の全範囲、画質の決定を意味しない。

## 実素材4点

読込段階で確認した写真2枚・動画2本を同じブラウザのファイル選択から指定した。原本の本体はアップロードせず、ローカルの設定済みフォルダーへ照合した。自動で作った60秒の初案を1280×720、30fps、H.264/AACのMP4へ書き出せた。この出力設定は試作上の選択である。

独立したPyAVの検査で1800フレームを全件デコードし、4場面の順に対応する代表位置を検査した。縦写真と回転情報を持つ縦動画は左右に余白があり、写真区間の音声は無音、動画2区間の代表位置は無音値のみではなかった。これは聞き取りや音質の評価ではない。

完成物はブラウザで60秒・1280×720として読み込め、消音されていない状態で再生時間が進んだ。保存リンク経由で取得したMP4は、プレビューが参照する生成物とSHA-256が一致した。生成物は6,893,654 bytesだった。原本・生成物・画面記録・個別の検査結果は非公開とする。

## 操作と合成素材

画面で写真を動画へ差し替え、開始2秒・終了4秒へ調整し、別の動画場面を除外した。採用へ戻す操作も確認した。開始より前の終了位置はエラーになり、有効な編集状態は維持された。編集後は保存できず、プレビューを更新すると保存できた。

編集後の12秒・360フレームを独立にデコードした。先頭は指定した2〜4秒の緑色の映像・880Hzの音で、その後の縦写真と回転情報付き縦動画には左右の余白と無音があった。除外した場面は出力に含まれなかった。素材生成時の旧コマンドでは回転値が0だったため、原本の値が90であることを独立に確認して作り直し、この検査をやり直した。旧素材での検査を回転対応の証拠にしない。

8件の自動テストが成功した。範囲は初案と編集、原本の照合、出力の映像・音声、HTTP経路とエラー復帰。独立レビューで見つかったルート外シンボリックリンクの読込、再選択後の版番号の再利用、不正な差し替えIDの3件には、修正前に失敗し修正後に成功する検査を追加した。

PC画面のレビューは通過した。除外カードを薄くする表示は、再採用ボタンのコントラストも下げるため、軽微な改善点として残る。モバイル画面の検証結果には広げない。
