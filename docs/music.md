# 同梱BGM

`moment_draft.music` は動画の試作に使う3曲の器楽音源を生成する。曲名は「穏やか」「軽やか」「余韻」。いずれも48 kHz、ステレオ、16-bit PCMのWAVで、再生時間は約72〜80秒。映像への音量調整と原音とのミックスはレンダラーが担当する。

`catalog()` は各曲の `id`、日本語の `name` と `description`、生成WAVの `license` を返す。`ensure_track(track_id, cache_dir)` は曲を必要なときだけ生成してWAVのパスを返す。既存ファイルの形式と長さが合わない場合は作り直す。未登録のIDと `off` は `ValueError` になる。無音の選択は呼び出し側が扱う。

音源には外部の録音、サンプル、曲、旋律、音楽APIを使っていない。和音進行と旋律は [`music.py`](../moment_draft/music.py) に記録されており、正弦波の合成で演奏する。毎回同じPCMが生成される。生成処理は1小節ずつWAVへ書き、完成後にキャッシュのファイル名へ置き換える。

コードはリポジトリのApache-2.0ライセンスに従う。生成WAVの利用条件と権利範囲は [`MUSIC_LICENSE`](../MUSIC_LICENSE) に記す。この3曲は試作用の選択肢で、利用者の好みや完成映像への適合性は未検証。
