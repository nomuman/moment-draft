# 公開試用へ進むための確認

この文書は試用版の実装と確認範囲を記録する。公開、契約、決済、外部AIへの素材送信を承認するものではない。

## 実装した範囲

PCブラウザから写真と動画を選び、初案を再生し、候補への差し替え・採用・除外・動画の前後調整・BGM選択を保存できる。プレビューとダウンロードは同じMP4を使う。途中送信の再開、再起動後の復元、書き出しの取消・再試行、利用者ごとの閲覧制限と期限を実装した。

試用出力は横長16:9、720p、30fpsのH.264/AACで、縦素材を切り取らず余白で収める。写真は3秒、動画は時間帯ごとの約6秒を候補にする。これは試用時の選択であり、表情・会話・感情の判定や本人の好みに合う品質を保証しない。

## 確認済みの証拠

- ブラウザで合成写真・動画を取り込み、候補を差し替え、2〜4秒に調整し、1場面を除外してBGMを付けた。9秒のMP4をダウンロードし、全270フレーム、色、縦余白、元の880Hz音とBGMを別の復号処理で確認した。再読み込み後も編集版と曲が残った。
- 実写真と向き情報のある動画を手元のサービスに送り、再生・再起動後の復元を確認した。素材の公開や外部AIへの送信は行っていない。
- 一時テストCAを指定したローカルTLS経路で、証明書とホスト名、Secure Cookie、別所有者からの拒否、部分ダウンロード、CSRF・Origin・直接HTTPの拒否、実プロセス再起動後の復元を確認した。公開ホストやブラウザへの証明書導入を行った結果ではない。
- 独立レビューで見つかった所有権、処理の終了待ち、古い版の再試行、失敗素材の容量解放、サムネイルの版競合、招待リンクからの入場を修正した。

最新のLinux・コンテナ検証は[CI](https://github.com/nomuman/moment-draft/actions)で確認する。Macだけの成功をLinuxの成功とみなさない。CIの合成素材の完走を、100点すべての実素材・同時利用・本番の安定性の証明とみなさない。

## 公開先で残る判断

公開先とドメインは未選定で、費用を支払う契約やデプロイは行っていない。最初はコードで入場を制限した単一ホストの試用とし、新規の保存先を使う。対象ホストでTLS、信頼するプロキシ、バックエンドの直接到達拒否、Cookie、実素材の再生と復元を確認する。手順は[運用文書](operations.md)にある。

保存は作成から7日、延長なしを暫定設定とした。期限後は直ちに閲覧を拒否し、稼働中は60秒ごとに期限切れの所有コピーを削除する。処理中のファイルは解放後に削除する。停止・障害による遅れ、端末の原本、ダウンロードしたコピー、サービス外のバックアップを含めて削除完了を約束しない。公開時には、この保持方針と運用者・問い合わせ先・バックアップ方針を決める。

Jevの利用アカウント、画像入力に適用される契約上の保持条件・ZDR範囲、実費用は未確認である。画像機能の有効化だけでZDRになったとは扱わない。アカウントと送信先、縮小・向き補正・不要メタデータの除去、費用上限、本人の送信許可を具体化した後に、まず合成素材で疎通する。同じ候補を使った単純選別との比較は未実施である。

料金500円、初案まで1〜3分、本人の手直し5分以内は目標・仮説のままである。実請求と同じテストセットの処理・保管・転送を計測するまで原価や性能保証に置き換えない。課金・決済、アカウント回復、複数ホストでの運用は今回の試用版には含めない。
